# /backups — Inventory Data Backups

Store your exported JSON backup files here.

## How to create a backup:

1. Open the dashboard
2. Click **⬇ Export Data** in the header
3. Save the downloaded `.json` file to this folder

## Naming convention:

`mjc_inventory_YYYY-MM-DD.json`

Example: `mjc_inventory_2026-05-31.json`

## How to restore a backup:

1. Open the dashboard
2. Click **⬆ Import Data**
3. Select the `.json` file from this folder
