# /libs — Library Files

This folder should contain the following files after running the setup script:

| File                 | Source                                                                        |
| -------------------- | ----------------------------------------------------------------------------- |
| JsBarcode.all.min.js | https://cdnjs.cloudflare.com/ajax/libs/JsBarcode/3.11.5/JsBarcode.all.min.js  |
| lz-string.min.js     | https://cdnjs.cloudflare.com/ajax/libs/lz-string/1.4.4/lz-string.min.js       |
| qrcode.min.js        | https://cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js           |
| supabase.min.js      | https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2/dist/umd/supabase.min.js |

## To download these files, run from the project root:

- **Mac/Linux:** `bash setup.sh`
- **Windows:** Double-click `setup.bat`

Once downloaded, use `inventory_dashboard_offline.html` instead of the online version.
