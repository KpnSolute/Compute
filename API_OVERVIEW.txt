┌─ AUTHENTICATION FLOW ───────────────────────────────────────────────────────────┐
│                                                                                 │
│  Admin/Manager (Supabase Auth):                                                 │
│  ────────────────────────────────────────────────────────────────────────────   │
│  1. Frontend: Auth with Supabase → Get JWT access_token                         │
│  2. POST /api/auth/login {access_token}                                         │
│  3. Backend: Validate JWT → Fetch user profile → Return token + user info       │
│  4. Frontend: Store token in localStorage                                       │
│  5. All requests: Authorization: Bearer <JWT>                                   │
│                                                                                 │
│  Staff (PIN Login):                                                             │
│  ────────────────────────────────────────────────────────────────────────────   │
│  1. POST /api/auth/login {username, pin}                                        │
│  2. Backend: Look up user → Verify PIN → Return pin_<user_id> token            │
│  3. Frontend: Store token in localStorage                                       │
│  4. All requests: Authorization: Bearer pin_<user_id>                           │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

│    "username": "john_staff",                 }                                  │
│    "email": "john@local",                                                       │
│    "role": "staff",                          Examples:                          │
│    "active": true,                           • Missing authorization token      │
│    "created_at": "2026-06-03T..."            • Invalid or expired token        │
│  }                                           • User profile not found           │
│                                              • Username already exists          │

│                                              • Database error                  │
