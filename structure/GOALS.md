# Project Goals

## Primary

- Track monthly cafeteria inventory for Miami Job Corps
- Process US Foods and Multi-Flow invoices
- Generate printable monthly reports
- Manage inventory across 9 categories

## Technical

- Python/Flask backend with Supabase (PostgreSQL)
- AI-powered invoice parsing (Gemini + Groq)
- Role-based access (staff, manager, admin)
- Single-page dashboard frontend (vanilla HTML/CSS/JS)
- Docker/Gunicorn deployment

## Future

- Add automated tests
- Set up CI/CD pipeline
- Improve error handling and monitoring
