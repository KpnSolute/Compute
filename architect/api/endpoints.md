# API Endpoints

## Auth
- POST /api/auth/login
- GET /api/auth/me
- POST /api/auth/logout

## Inventory
- GET /api/inventory
- POST /api/inventory
- PATCH /api/inventory/<id>
- DELETE /api/inventory/<id>

## Invoices
- POST /api/invoice/parse

## Barcodes
- POST /api/barcodes/generate
- POST /api/barcodes/decode
